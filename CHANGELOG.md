# Changelog

All notable changes to Development Kit are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [0.3.0] — 2026-10-26

First public build.

### Added
- **Server control** — start, stop and restart FXServer from an embedded terminal.
- **Console** — live server output with error/warning filters and saved commands.
- **Resources** — browse workspace resources and open them in VS Code.
- **Assets** — list every streamed file in the workspace.
- **Resmon** — per-resource and per-thread timings from FXServer profiler traces.
- **HeidiSQL** — docked inside its own tab.
- **Launch FiveM** — connect the local client to the dev server.
- **Application discovery** — locates FiveM, HeidiSQL and VS Code automatically.
- **Activity feed** — timeline of server and app events.
- **Accounts** — sign-in with remembered and automatic login options.
- Keyboard shortcuts for common actions.
- Windows installer.
